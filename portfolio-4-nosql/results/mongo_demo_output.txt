========================================================================================
M8  Multi-document ACID transaction - pharmacy dispenses an open prescription
========================================================================================
Two documents in two collections must change together: drug_stock (minus quantity) and the
prescription status inside the patient document. This needs a replica set and a transaction.
open prescription: patient GC00001291, Aspirin 75mg x30
  stock too low   : start stock   29 -> ABORTED (insufficient stock: have 29, need 30); stock after = 29; prescription still open = True
  stock sufficient: start stock  130 -> COMMITTED; stock after = 100; prescription still open = False
In the aborted run both writes had already been made inside the transaction; abortTransaction
undid both. In the committed run both became visible together (all-or-nothing across documents).
